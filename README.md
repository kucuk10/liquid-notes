# Liquid Notes

A simple multi-platform SwiftUI note-taking app skeleton that supports three notepad types:

- **Post-It Notes** – quick text notes similar to Apple Notes.
- **Notebooks** – paged notes for longer documents.
- **Canvases** – infinite canvas for freeform ideas.

The app includes basic tabs for Recents, note lists, and search, along with a toolbar for creating new notepads.

This project is a starting point and does not yet implement full editing, iCloud sync, or PencilKit integration.
